# Contract: States CSV Format (16 fields)

**Requirements**: FR-001 to FR-006 | **Stories**: US1

This replaces the **Fields** and **Header line** sections of
`specs/006-activity-states/contracts/states-csv-format.md`. That contract's **File** section and its
Mean and Difference rules still apply unchanged. If this contract and the spec disagree, the spec
wins.

## Fields

Every line has exactly 16 fields, which means 15 `|` characters. "The set" is the StateSet the row
summarizes. Every value comes from the activity CSV's written values.

| # | Header | Value | Empty when |
|---|--------|-------|------------|
| 1 | `ActivityId` | the set's ActivityId | never |
| 2 | `ActivityDistanceMiles` | `DistanceMiles` of the set's last row with one, as written | no row in the set has one |
| 3 | `ActivityElapsedTime` | `ElapsedTime` of the set's last row with one, as written | no row in the set has one |
| 4 | `ActivityElapsedSeconds` | `ElapsedSeconds` of the set's last row with one, as written | no row in the set has one |
| 5 | `State` | the set's State | never |
| 6 | `StateEndDate` | `Time` of the set's last row with a Time, as written | no row in the set has a Time |
| 7 | `StateEndTrackpointNum` | `TrackpointNum` of the set's last row | never |
| 8 | `StateTrackpointCount` | the number of rows in the set, as an integer with no sign, separators, or leading zeros | never |
| 9 | `StateElapsedSeconds` | `StateSeconds` of the set's last row with one, as written | no row in the set has one |
| 10 | `StateDistanceMiles` | the set's last `DistanceMiles` minus the last `DistanceMiles` before the set (0 when none). This was `DistanceMiles` in feature 006 | no row in the set has one |
| 11 | `AverageHeartRateBpm` | mean of the set's `HeartRateBpm` values | no row in the set has one |
| 12 | `AverageRunCadence` | mean of the set's (doubled) `RunCadence` values | no row in the set has one |
| 13 | `AverageLatitude` | mean of the set's `Latitude` values | no row in the set has one |
| 14 | `AverageLongitude` | mean of the set's `Longitude` values | no row in the set has one |
| 15 | `AverageAltitudeMeters` | mean of the set's `AltitudeMeters` values | no row in the set has one |
| 16 | `AverageAltitudeFeet` | mean of the set's `AltitudeFeet` values | no row in the set has one |

Over one activity:
- the StateTrackpointCount values add up to the activity CSV's row count
- the last row's ActivityDistanceMiles and ActivityElapsedSeconds are the activity CSV's last
  non-empty DistanceMiles and ElapsedSeconds, byte for byte

## Header line (exact)

```text
ActivityId|ActivityDistanceMiles|ActivityElapsedTime|ActivityElapsedSeconds|State|StateEndDate|StateEndTrackpointNum|StateTrackpointCount|StateElapsedSeconds|StateDistanceMiles|AverageHeartRateBpm|AverageRunCadence|AverageLatitude|AverageLongitude|AverageAltitudeMeters|AverageAltitudeFeet
```

## Earlier files

A file with feature 006's 13-field header is a `HeaderMismatch` on line 1. Both pages show it as the
wrong format, with a link to convert the TCX file again (FR-006). It is never read or rewritten.

## Worked example (synthetic, the 006 scenario extended)

38 walking rows (ElapsedSeconds 0–37), then 113 running rows (38–150), one per second:

| State | ActivityElapsedSeconds | StateEndTrackpointNum | StateTrackpointCount | StateElapsedSeconds |
|-------|------------------------|-----------------------|----------------------|---------------------|
| walking | 37 | 38 | 38 | 37 |
| running | 150 | 151 | 113 | 113 |

38 + 113 = 151, the activity CSV's row count.
