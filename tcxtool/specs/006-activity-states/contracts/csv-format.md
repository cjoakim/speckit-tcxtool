# Contract: Activity CSV Format (19 fields)

**Requirements**: FR-001 to FR-006, FR-010, FR-017 | **Stories**: US1

This contract replaces the field list of `specs/002-tcx-to-csv/contracts/csv-format.md`. Everything
that contract says about the **file** (location, names, UTF-8 without BOM, `\n` after every line,
`|` never quoted or escaped, one header plus one line per trackpoint, an existing file replaced) and
about **shortest decimals** and **text cleaning** still applies. If this contract and the spec
disagree, the spec wins.

## Fields

Every line has exactly 19 fields, which means 18 `|` characters. Fields 1–12 and 16–19 are
feature 002's fields 1–12 and 14–17, unchanged.

| # | Header | Value | Empty when |
|---|--------|-------|------------|
| 1–12 | `ActivityId` … `HeartRateBpm` | as feature 002 | as feature 002 |
| 13 | `RunCadence` | **TCX `RunCadence` × 2**, shortest decimal (`59` → `118`, `59.5` → `119`) | no extension RunCadence |
| 14 | `State` | `stopped` (RunCadence = 0), `walking` (0 < RunCadence < 150), `running` (RunCadence ≥ 150), `unknown` (RunCadence empty or negative) | never |
| 15 | `StateSeconds` | elapsed time minus the StateSet's start, shortest decimal (below) | no Time |
| 16–19 | `DistanceMeters` … `AltitudeFeet` | as feature 002 | as feature 002 |

**StateSet**: a longest run of consecutive rows with the same `State`, in file order.

**StateSet start**: the elapsed time of the last row *before* the set that has a Time, or 0 when no
earlier row has one. The first set therefore starts at 0, and every later set starts where the
previous set's last timed row was.

**StateSeconds** is calculated from the two elapsed times as durations, then written like
`ElapsedSeconds`. It is never the difference of two written decimals, so `3725.6 − 0.3` is `3725.3`.

## Header line (exact)

```text
ActivityId|Date|DeviceName|DeviceId|Sport|TrackpointNum|Time|ElapsedSeconds|ElapsedTime|Latitude|Longitude|HeartRateBpm|RunCadence|State|StateSeconds|DistanceMeters|DistanceMiles|AltitudeMeters|AltitudeFeet
```

## Worked example (synthetic values)

TCX cadence 70, 70, 80, 80, then a missing cadence, at one trackpoint per second from 0:

| TrackpointNum | ElapsedSeconds | RunCadence | State | StateSeconds |
|---------------|----------------|------------|-------|--------------|
| 1 | 0 | 140 | walking | 0 |
| 2 | 1 | 140 | walking | 1 |
| 3 | 2 | 160 | running | 1 |
| 4 | 3 | 160 | running | 2 |
| 5 | 4 | | unknown | 1 |

## Older files

A file with feature 002's 17-field header is not in this format. `ActivityCsvReader` returns
`HeaderMismatch` at line 1 for it, and the app never reads or rewrites it (FR-017).

  regenerated by `Fixtures/generate_success_fixtures.py`, independently of the C# code (research
